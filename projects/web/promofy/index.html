Promofy

A secure, transparent, and bot-protected YouTube traffic and view exchange platform designed to help content creators organically boost engagement.

Visit Platform

How It Works

Promofy operates on a community-driven mutual assistance model. Creators watch each other's videos to earn virtual credits (quotas), which they can then reinvest to promote their own channels.

  • Registration: New creators sign up and receive a starting bonus of 100 credits to test the service.
  • Watch & Earn: Members navigate to the "Watch" hub, view a video from another community member for a set duration (e.g., 60 seconds), and receive quota rewards.
  • Create Campaigns: Earned quotas are spent to promote YouTube videos. Users define target view counts and watch time ranges (45 to 600 seconds) to ensure meaningful audience retention.
  • Stripe Integration: Creators who lack the time to manually watch videos can purchase credit packages (from "Spark" to "Scale") using secure fiat transactions.

Technical Architecture & Stack

The platform is engineered on a lightweight, high-performance Node.js stack. By avoiding bulky frontend frameworks, it achieves near-instant page load times and minimal server resource consumption.

Backend Framework

Express.js powers the server logic, handling routing, dynamic page rendering, and API request validation.

In-Memory Database

Upstash Redis serves as the database. It provides sub-millisecond read/write speeds, making it ideal for credit transactions, session management, and rate-limiting.

Full Localization

Integrated i18next supporting 4 languages (English, Ukrainian, Polish, Russian) to ensure usability for a global creator audience.

Security & Anti-Cheat Infrastructure

Protecting user data and guaranteeing genuine video views to promoting channels are top priorities. The platform features robust security and anti-fraud modules.

  • Credentials & Sessions: Passwords are secured using bcrypt with a cost factor of 10. Sessions are managed securely via express-session cookies.
  • PCI-Compliant Payments: No credit card or billing details touch the server. Payments are fully delegated to Stripe Checkout, and transactions are securely verified via HMAC-SHA256 signature checks on Stripe webhooks.
  • Bot Protection: Forms are safeguarded from brute-force attempts and automated spam registrations using Cloudflare Turnstile's invisible captcha.
  • YouTube API Anti-Cheat:
    • Videos play via the official iframe API with player controls disabled (controls: 0) to prevent fast-forwarding or scrubbing.
    • The browser visibilitychange event pauses playback and freezes rewards timers whenever the tab is switched or minimized.
    • Beken API checks confirm that watch duration was actually completed, and log watched task histories to prevent duplicate credit redemption.
  • Right to be Forgotten: Users can deactivate accounts. Active campaigns are paused instantly, and all user data is permanently deleted from Redis after a 14-day grace period.
